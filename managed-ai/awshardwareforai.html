AWS AI Practitioner Study Guide

Amazon Hardware for AI

Amazon EC2, which means Elastic Compute Cloud, is one of the most popular offerings from AWS.

  • This is where you get your servers as part of an infrastructure as a service (IAAS) model.

While EC2 is not as central from an AI perspective because we often use managed AWS services, it's still important to have an overview.

  • EC2 is fundamentally about renting virtual machines or servers in the cloud, and knowing how it works is key to understanding the cloud itself.

Amazon EC2 Overview

When you have your virtual server, you can configure many aspects of it. You are pretty much creating a virtual computer on which you define what you want on it and how powerful you want it to be.

  • You can attach disk space to these servers using EBS drives.

  • You can distribute traffic to your Amazon EC2 instances through load balancers (ELB).

  • You can scale the service automatically using auto-scaling groups (ASG).

You can also define the following for your virtual server:

  1. Operating System: Choose from Linux, Windows, or Mac OS.

  2. Compute & Memory: Define how much compute (CPU cores) and Random Access Memory (RAM) you want.

  3. Storage Space: Specify how much storage you need, which can be network-attached or hardware-based.

  4. Network & IP: Define how fast you want the network to be and if you want a public IP.

  5. Firewall Rules: If you are exposing the server, you can set firewall rules called security groups.

  6. Launch Configuration: To configure your virtual server at launch, you can use EC2 User Data.

Amazon EC2 for Artificial Intelligence (AI)

When you create an Amazon EC2 instance, you must select an instance type. Some EC2 instances are based on GPUs or specialized machine learning chips, making them desirable from an AI perspective.

1. GPU-Based Instances

  • A GPU (Graphical Processing Unit) is a very good processor that allows you to perform machine learning.

  • EC2 families like the P family (P3, P4, P5) and the G family (G3, G6) have powerful GPUs and are great for machine learning.

2. AWS Trainium

  • These are machine learning chips used to perform deep learning on big models with over 100 billion parameters.

  • You would use these servers to train models if, for example, you don't want to use SageMaker.

  • The Trn1 instance, for example, will have 16 Trainium accelerators and can provide a 50% cost reduction for training.

AWS Inferentia

  • This is a machine learning chip built by AWS for running inference at very high performance and low cost. You can use these servers to serve the models.

  • Inf1 or Inf2 instances are powered by AWS Inferentia.

  • Using these chips can result in up to 4 times the throughput of a normal GPU-based instance and up to a 70% cost reduction.

Environmental Footprint

  • Something that can appear in the exam is that the Trainium and Inferentia instances have the lowest environmental footprint because they are the most efficient.

Exam Summary

From an exam perspective, remember that EC2 instances are virtual servers and they can be of different types. You have GPU-based types and also the ones based on AWS Trainium and AWS Inferentia.

Important Note:

  1. AWS Trainium is ML chip for training of DL models

  2. AWS Inferentia is ML chip for serving the model.
